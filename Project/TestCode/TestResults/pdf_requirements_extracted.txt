Software Engineering Project: Offline 
Accessible Multimodal Local Content 
Retrieval System
 
Duration: 8 Weeks (2 Months) 
 
Project Background
 
This project aligns with our founding mission: to organize the world's information and make it universally 
accessible and useful. It replicates the end-to-end software engineering workflow of core product teams, 
focusing on solving a real user pain point: billions of users including people with visual impairments are 
struggling to efficiently search and retrieve unstructured local content across personal devices, such as 
PDFs, documents, images, screenshots. Existing solutions are often cloud-dependent, paid, lack robust 
accessibility features, or fail to support semantic multimodal search.
Core Project Goals
 
1. Build a fully open-source, offline-first, cross-platform multimodal local content retrieval tool
2. Meet WCAG 2.1 AA accessibility standards, aligned with global accessibility commitments
3. Deliver production-grade code, full documentation, and a deployable end product following software 
engineering best practices
Core Tech Stack
 
Cross-platform UI: Flutter
ML Inference: TensorFlow Lite (end-side inference framework)
Multimodal Models: BERT (text embedding) + MobileCLIP (image embedding)
Document Parsing: PDFium (Chromium PDF engine) + Apache Tika
Vector Storage: Chroma DB (local vector database)
Testing: Google Test + Flutter Test
Version Control: Git + GitHub
Accessibility Validation: Google Accessibility Scanner + WAVE
