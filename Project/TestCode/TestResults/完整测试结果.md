# V8 完整测试与覆盖率结果

## 结论

V8 已具备独立测试目录、完整测试代码和可自动失败的覆盖率门槛。按照基础 PDF 对程序主体测试的要求，本次已在 V8 目录重新执行单元测试、集成测试、界面测试、真实本地服务链路测试和压力测试。

- Flutter/Dart：231 项测试全部通过，0 项失败。
- Python 本地服务与发布工具：96 项测试全部通过，0 项失败。
- Windows 原生 Google Test：3 项测试全部通过，0 项失败。
- Flutter 核心模块合计行覆盖率：4335 / 4778，90.73%。
- Flutter 文件解析模块行覆盖率：1377 / 1575，87.43%，高于 PDF 的 80% 阶段门槛。
- Flutter 嵌入模块行覆盖率：796 / 884，90.05%，高于 PDF 的 85% 阶段门槛。
- Python 服务行覆盖率：2319 / 2509，92.43%。
- Python 每个实际服务模块均单独达到 90% 以上，不再由高覆盖模块掩盖低覆盖模块。

Flutter 核心覆盖率范围固定为：`lib/core`、`lib/domain`、`lib/embedding`、`lib/indexing`、`lib/query`、`lib/retrieval`、`lib/storage`、`lib/summary`。界面表现层、应用编排层和操作系统窗口胶水代码不混入核心模块覆盖率分母。

Python 覆盖率范围为 `Project/ReleaseCode/services` 下全部本地服务代码，没有通过删除低覆盖模块缩小统计范围。

`Testing/verify_coverage.py` 会同时读取 Flutter LCOV 和 Python JSON 报告，并按 PDF 中的阶段门槛与最终门槛自动失败。本次结果为：

```text
Flutter core aggregate: 4335/4778 = 90.73% (minimum 90%)
Flutter parsing module: 1377/1575 = 87.43% (minimum 80%)
Flutter embedding module: 796/884 = 90.05% (minimum 85%)
Python services aggregate: 2319/2509 = 92.43% (minimum 90%)
Python individual service modules: 90.28%–98.25% (minimum 90%)
Coverage gate passed.
```

Python 测试命令本身也使用 `--cov-fail-under=90`，避免仅在报告中显示整数 90% 而精确覆盖率实际不足。

## PDF 要求复核边界

程序测试已经实际使用 Flutter Test 与 Google Test，并覆盖单元、集成、端到端、压力、性能、真实模型准确率和发布工具。运行期网络检查显示本地 Chroma 只绑定 `127.0.0.1`，浏览器解析明确屏蔽外部网络；依赖安装器是用户主动安装依赖时使用的独立联网路径。

PDF 指定的 Google Accessibility Scanner 是 Android 工具，WAVE 是网页工具，不能对 Windows Flutter 桌面程序进行等价扫描；本项目已有 Flutter 语义、键盘导航、高对比度、动态字号与最小点击区域自动化测试，但这不能冒充上述两种工具的实际扫描。NVDA 人工听读、VoiceOver、真实用户可用性测试以及 macOS/Linux 真机构建也仍需对应环境或人员执行。
