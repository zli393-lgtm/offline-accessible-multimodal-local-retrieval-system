# Third-party notices

The project source is licensed under Apache-2.0. This does not relicense any
third-party component. A release must retain this file, `LICENSE`, `NOTICE`,
Flutter's generated license notices, and the license/legal directories bundled
with native runtimes.

## Models and data shipped in every release

| Component | Source | Declared license | Distribution action |
|---|---|---|---|
| BERT model/tokenizer | google-research/bert | Apache-2.0 | Retain Apache-2.0 text and attribution. |
| CLAP HTSAT fused weights | laion/clap-htsat-fused | Apache-2.0 in the model card | Retain model card, source and license declaration. |
| Faster Whisper medium weights | Systran/faster-whisper-medium, converted from OpenAI Whisper | MIT | Retain model card and MIT notice. |
| MobileCLIP S0 weights | apple/MobileCLIP-S0, revision recorded in `model_sources.json` | Apple Machine Learning Research Model License Agreement | Research-only and non-commercial. Include the complete Apple agreement and required attribution. Do not describe this weight as Apache-2.0 or commercially distributable. |
| Tesseract trained data | tessdata project | Apache-2.0 | Retain license and source attribution. |
| Noto Sans SC font | Noto Fonts | SIL Open Font License 1.1 | Retain OFL text with the font. |

## Application and document-processing components

- Flutter and Dart packages: retain the license notice generated by Flutter and
  review every exact package version in `pubspec.lock` before release.
- Apache Tika: Apache-2.0. Preserve its license and NOTICE content.
- TensorFlow Lite / LiteRT: Apache-2.0, subject to bundled third-party notices.
- Chroma DB and all Python packages: preserve every `.dist-info` license and
  NOTICE directory included in the Python runtime. Package metadata must be
  inventoried from the exact runtime used for the release, not from a generic
  requirements list.
- Python, Java, Tesseract, PDFium, DjVuLibre, GhostPDL and JPEG XR: retain each
  runtime's original LICENSE, COPYING, NOTICE, legal and third-party files.
  These components are not relicensed by this project.

## Release gate

Before public distribution, produce a machine-generated inventory from the
exact release directory and resolve every entry whose license is missing,
unknown, custom, non-commercial, copyleft, or requires source-code delivery.
The current MobileCLIP weight makes the bundled package research-only. A
commercial/general-purpose release must either obtain compatible permission or
replace that weight with a redistributable compatible model; removing its
license notice is not a solution.

This file is an engineering compliance record, not legal advice.
