# 可打包依赖许可证入口

所有下载到 `Dependencies/Packageable` 的模型、数据和工具都必须具备明确来源、
固定版本或修订号、校验值、许可证标识和必要的许可证正文。

当前统一清单位于：

- `Dependency-Download-and-Setup-Guide.md`：依赖来源、固定版本和放置位置。
- `../Project/ReleaseCode/THIRD_PARTY_NOTICES.md`：项目级第三方通知与发布限制。
- 下载依赖自身的 `LICENSE`、`NOTICE`、`README` 或模型卡：原始法律文本和归属。

项目的 Apache-2.0 `LICENSE` 不能替代第三方许可证。特别是 MobileCLIP S0 权重
受 Apple Machine Learning Research Model License Agreement 约束，只能用于其
许可证允许的用途；公开分发权重前必须同时保留官方许可证正文和要求的归属信息。
