# 测试报告

测试日期：2026-10-21

## 结论

当前 Windows 环境中的自动化测试、核心覆盖率门槛、Windows 构建和两种 Windows 发布方式验证均已通过。Linux 和 macOS 已进行代码及发布分支检查，但仍需在对应操作系统进行真实构建、屏幕阅读器和运行验证。

## 自动化测试结果

- Flutter/Dart：231 项通过，0 项失败。
- Python 本地服务与发布工具：96 项通过，0 项失败。
- Windows 原生 Google Test：3 项通过，0 项失败。
- Flutter 核心模块行覆盖率：4335 / 4778，90.73%。
- 文件解析模块行覆盖率：1377 / 1575，87.43%。
- 嵌入模块行覆盖率：796 / 884，90.05%。
- Python 服务行覆盖率：2319 / 2509，92.43%。
- Python 每个实际服务模块覆盖率：90.28% 至 98.25%。

以上结果达到 PDF 要求的解析模块 80%、嵌入模块 85% 和最终核心模块 90% 覆盖率门槛。

## 集成与端到端测试

已覆盖真实文本解析、BERT、Chroma、文件对象索引、查询附件、主要页面、设置、弹窗、无障碍语义、危险操作入口以及发布工具。测试还验证了文件级索引事务、查询结果去重、准确总数、稳定分页和本机回环服务限制。
