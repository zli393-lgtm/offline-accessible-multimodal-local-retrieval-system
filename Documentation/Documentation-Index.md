# 文档目录

本目录是项目正式开源内容和发布内容的一部分，不是临时开发资料。发布源码包或
生成用户发布包时必须完整保留，不能因为它位于 `Project` 之外而剔除。

当前文档：

- `README.md`：项目入口、目录结构、编译、测试、无障碍、依赖与许可证概览。
- `CONTRIBUTING.md`：代码、测试、无障碍与第三方依赖的贡献要求。
- `Technical-Documentation.md`：系统架构、主要模块、内部接口和维护要求。
- `User-Manual.md`：安装、索引、查询、无障碍操作及配置清理说明。
- `Test-Report.md`：覆盖率、集成与端到端测试、性能、准确率和发布验证结果。
- `Open-Source-Compliance-Report.md`：项目许可证、第三方依赖和发布合规要求。
- `Release-Packaging-Guide.txt`：六种发布目标所需依赖、目录结构、编译命令、
  校验方式与发布前检查。其中 Windows 两种方式已经在当前设备完成配置校验。
- `Dependency-Classification.md`：依赖的跨平台属性和分类原则。
- `Dependency-Licenses.md`：可打包依赖的许可证入口和再分发边界。
- `Required-External-Dependencies.md`：需要用户或目标系统提供的外部依赖。
- `Dependency-Download-and-Setup-Guide.md`：从 GitHub 获取源码后，下载全部模型、
  OCR 数据、文档解析组件和各平台运行时，并放入项目规定目录的操作说明。

上述四份主体文档对应 PDF 最终交付清单中的技术文档、最终用户手册、测试报告
和开源合规报告。编译、依赖及发布细节由后三份专项文档补充，不再拆分成大量重复
文件。
