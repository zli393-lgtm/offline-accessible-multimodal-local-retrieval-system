# 用户安装与操作手册

## 安装与首次启动

Windows 用户可以使用自包含版或外置依赖版。自包含版携带运行依赖；外置依赖版需要在“设置”中完成依赖路径配置。详细编译和发布方法见 `Release-Packaging-Guide.txt`。

首次启动时，程序会按系统语言显示初始化提示。默认界面采用无障碍设置。用户可以直接进入设置页调整语言、字号、界面空间、颜色、高对比度和色觉无障碍模式，并选择数据库、日志及本地依赖位置。

依赖查找顺序为：已保存的用户配置、程序自带依赖目录、系统环境变量、常见安装位置。仍未找到的依赖由用户通过目录选择器指定；路径只用于显示和检查，不要求手工输入。

## 建立和更新文件库

1. 打开左侧“文件库”。
2. 选择“指定路径”或“全部设备”。选择全部设备时程序会提示时间与空间风险。
3. 使用文件或文件夹选择器添加扫描范围；必要时加入排除路径。
4. 选择标准核对预设，或调整需要核对的项目。
5. 点击“扫描并更新”。界面会显示当前阶段、进度，并允许暂停、继续或停止。
6. 完成后查看成功和失败数量；打开高级信息可以查看每个文件的结果。

一个文件只对应一个文件对象。文件内部任一必要阶段失败时，该文件的新索引不会提交；其他文件仍可继续处理。索引日志同时记录成功和失败条目。

## 查询文件

1. 打开左侧“查询”。
2. 输入查询文字，或者通过附件按钮选择一个或多个查询文件；二者可以分别使用。
3. 通过文件夹选择器添加查询范围。没有选择范围时按界面说明使用已有索引范围。
4. 选择查询数据类型。文件名始终参与查询；其他类型包括原生文字、提取文字、图像信息、音频信息和总体摘要。
5. 根据需要启用内容摘要、语义摘要及高级后缀范围。
6. 选择关联度等级并开始查询。
7. 结果按文件对象分页显示。可通过界面箭头、左右方向键、Page Up 或 Page Down 切换页面。

结果列表分为文件名和完整路径。双击可以打开文件；右键菜单可以打开、选择打开方式、复制完整路径或在系统文件管理器中显示。若当前系统权限不足，由操作系统提示；程序不会在启动时强制申请管理员权限。

如果查询范围包含未建立索引的路径，可以查看这些路径、忽略未建立索引的部分继续查询，或者把未建立索引路径转交到文件库。转交时可选择覆盖原路径、合并路径或取消，然后由用户正常执行完整索引流程。

## 无障碍操作

- 所有主要操作均支持键盘焦点和 Tab 导航。
- 文件库、查询和设置可通过其已配置的键盘入口访问；快捷键提示不会长期占据侧栏文字。
- 主要控件具备屏幕阅读器名称、状态和说明。
- 字号及界面空间可以从无障碍默认值调整为更小或更大的预设。
- 颜色主题、高对比度和色觉无障碍模式彼此独立；高对比度只增强当前配色的对比度。
- 多选列表的全选控制具有全选、部分选中和全不选三种状态。
- 弹窗支持键盘操作、屏幕阅读语义和窗口缩放，调整大小使用系统窗口边缘及四角。

## 配置重置与数据清理

设置页末尾提供重置用户配置和清空索引。重置配置需要确认并重启程序，随后恢复默认语言、颜色、字号、路径和首次启动提示。清空索引有独立确认弹窗，只删除本程序建立的索引，不删除用户原始文件。
